# 🎬 سینما — دنیای فیلم و سریال

## ✨ امکانات

### 📂 بخش‌ها
- **🎬 فیلم‌ها** — ۱۱٬۵۰۰ فیلم با لینک دانلود مستقیم (زیرنویس / دوبله تفکیک‌شده)
- **📺 سریال‌ها** — ۲٬۸۰۰ سریال با گروه‌بندی فصل و زیرنویس/دوبله
- **🎬 سرمووی** — عنوان‌های به‌روز که هر ۶ ساعت از سرورهای سرمووی کرال می‌شوند (شامل انیمه)
- **⭐ معرفی** — ۵۷ پک تصویردار: فرنچایزها (مارول، DC، سریع و خشمگین، جان ویک، هری پاتر، جنگ ستارگان و…)، کارگردان‌ها (نولان، تارانتینو، اسکورسیزی، فینچر، ویلنوو، اسپیلبرگ)، پک‌های ژانری، پرفروش‌ترین‌های گیشه تاریخ، جواهرات پنهان و تازه‌ها

### 🔍 جستجوی دوگانه
- **جستجوی سراسری** در نوار بالا: در میان فیلم‌ها + سریال‌ها + سرمووی به‌صورت همزمان
- **جستجوی محلی** داخل هر بخش: فقط همان بخش را فیلتر می‌کند
- دکمه ✕ برای پاک‌کردن سریع هر جستجو

### 🖱️ پاپ‌آپ جزئیات (کلیک روی هر کارت)
- پوستر + تصویر بک‌دراپ، امتیاز IMDb / TMDB / Rotten Tomatoes / Metacritic
- خلاصه داستان، کارگردان، بازیگران، جوایز، ژانر، کشور، مدت، فروش
- **لینک‌های دانلود** با تفکیک 🔵 زیرنویس / 🔴 دوبله / 📀 فصل‌ها
- برای لینک‌های پوشه‌ای (کیفیت هر فصل): دکمه 📂 برای دیدن فایل‌های اپیزود داخل برنامه + دکمه **کپی همه لینک‌ها** برای دانلود لیستی در IDM و نرم‌افزارهای مشابه
- پنل «🌐 همین عنوان در سایت‌های دیگر» — جستجوی عنوان در ۷ سایت دانلود رایگان
- دکمه‌های IMDb و تحلیل در سینما اسکور

### 🖼️ کارت‌ها
- پوستر خودکار با زنجیره fallback (سرور خودمون ← TMDB ← placeholder)
- امتیاز روی پوستر، خلاصه داستان دو خطی، کیفیت‌ها، تعداد فصل واقعی

### 📴 PWA
- نصب روی موبایل و دسکتاپ، استفاده آفلاین
- کش هوشمند: پوسترها بین آپدیت‌ها حفظ می‌شوند
- تم تاریک/روشن با ذخیره انتخاب

## 🗃️ منابع داده

| منبع | استفاده | لینک |
|------|---------|------|
| **آپاراتچی (دنیای سریال)** | آرشیو فیلم/سریال + لینک دانلود | `dlsN.aparatchi-dlcenter.top` |

| **CineScore (سینما اسکور)** 🌟 | پوستر، بک‌دراپ، خلاصه، امتیازها، پک‌های معرفی | [github.com/mohsen-niksirat/CineScore](https://github.com/mohsen-niksirat/CineScore) |

### 🙏 درباره سینما اسکور (CineScore)
پوستر و اطلاعات تکمیلی (خلاصه داستان، امتیاز TMDB/RT/Metacritic، بازیگران، تریلر و…) از پروژه‌ی **[CineScore](https://github.com/mohsen-niksirat/CineScore)** گرفته می‌شود — یک دیتابیس متنباز فارسی که هر شب توسط کرالر خودش از TMDB / OMDb / Wikipedia به‌روز می‌شود و تصاویر و داده‌ها را روی GitHub Pages میزبانی می‌کند:

- `CineScore/public/titles.json` — نسخه سبک (~۱MB) برای پوستر و امتیاز سریع
- `CineScore/public/db.json` — نسخه کامل (~۱۱MB) برای جزئیات (در پس‌زمینه لود می‌شود)
- `CineScore/public/posters/` و `backdrops/` — تصاویر سلف‌هاست‌شده (قابل دسترسی حتی جایی که TMDB فیلتر است)
- خود اپلیکیشن CineScore: https://mohsen-niksirat.github.io/CineScore/

## 🔄 بروزرسانی خودکار (GitHub Actions)
- **Cinema** — هر ۶ ساعت کرالر (`scripts/crawl.js`) سرورهای سرمووی را می‌پیماید و `public/db.json` را به‌روز می‌کند
- **CineScore** — هر شب داده‌ها را از TMDB/OMDb/Wikipedia جمع می‌کند، پوسترها را سلف‌هاست می‌کند و `titles.json` / `db.json` را بازنویسی می‌کند

## 🚀 اجرا

## 📁 ساختار

```
├── index.html              # اپلیکیشن اصلی (تک‌فایل)
├── manifest.json / sw.js   # PWA
├── public/
│   ├── db.json             # خروجی کرالر سرمووی
│   ├── collections.json    # پک‌های تب «معرفی» (با کاور)
│   └── archive.json        # آرشیو (legacy)
├── scripts/
│   ├── crawl.js            # کرالر سرمووی (GitHub Actions)
│   └── build_collections.js# سازنده پک‌های معرفی (از دیتای CineScore)
└── .github/workflows/crawl.yml
```

## 🔧 سفارشی‌سازی

- **افزودن پک جدید**: در `scripts/build_collections.js` به آرایه `DEFS` اضافه کنید و اجرا کنید: `node scripts/build_collections.js`
- **منابع خارجی (سایت‌های دانلود)**: آرایه `EXT_SOURCES` در `index.html`
- **سرورهای سرمووی**: آرایه `SERVERS` در `scripts/crawl.js`
